# IT Study Lab | مختبر المذاكرة

Bilingual Arabic/English IT revision website with 97 practice questions, visual lessons, flashcards, timed mock exams, code exercises and dark mode.

Progress, language and theme preferences are stored locally in each visitor’s browser. No account is required.

Study questions are adapted from student review notes; they are not an official syllabus or guaranteed exam questions. Original PDFs and personal progress are not included.

Open index.html locally or serve this directory as a static website. GitHub Pages serves the main branch root.
